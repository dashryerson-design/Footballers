# Footballers

A physics ragdoll football (soccer) prototype: one player on an empty association football pitch, built on the Physics American Football engine.

[![Play in browser](https://img.shields.io/badge/%E2%96%B6%20PLAY%20IN%20BROWSER-2ea44f?style=for-the-badge)](https://dashryerson-design.github.io/footballers/)

**Keyboard:** WASD move · Shift sprint · Space jump · mouse look · F go limp / get up · R back to the centre spot · P pause
**Touch:** joystick, Sprint, Jump
